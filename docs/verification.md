# SafeScan web kontrol raporu

3 Kasım 2026. Henüz internet yayını yapılmadı.

- JavaScript sözdizimi kontrolü başarılı.
- Yerel kontrol: 5 HTML sayfası, 81 yerel bağlantı/anchor ve 203 çeviri/görsel/erişilebilirlik girdisi başarılı. Eksik dosya, bozuk iç bağlantı ve yinelenen HTML id bulunmadı.
- Tüm fontlar yerel; çalışma anında dış font/CDN/analitik servisi yok. Poppins OFL lisansı assets/fonts/OFL.txt içinde.
- Gerçek tarayıcıda masaüstü görünümü, 390 × 844 ve 320 × 740 mobil ölçüleri kontrol edildi. Test edilen sayfalarda yatay sayfa taşması bulunmadı.
- Özellik sekmeleri ve sağ/sol klavye geçişi; tek görünür panel kontrolü başarılı.
- Türkçe/İngilizce geçişi; sayfa başlığı, görsel alt yazıları, erişilebilirlik etiketleri ve gizlilik metni kontrol edildi. İngilizce gizlilikte 7 EN bölüm görünür, TR bölümler gizli.
- Açık/koyu tema ve sayfa geçişi/yükleme sonrası tercihlerin korunması kontrol edildi.
- Mobil menü açma/kapama ve destek sayfasına geçiş başarılı.
- Destek adresi kopyalama: gerçek tarayıcıda “E-posta adresi kopyalandı.” durumu doğrulandı. Mailto bağlantıları mevcut; gerçek destek e-postası gönderilmedi.
- SSS açma/kapama başarılı.
- Görüntülenen hero/özellik çizimleri yüklendi. Gizli panellerdeki lazy görseller gösterilene kadar yüklenmeyebilir; bu hata değildir.
- Son tarayıcı konsolu kontrolünde hata/uyarı yok.
- Mağaza bağlantıları bilinmediğinden düğmeler açıkça Yakında durumunda. Sonradan yalnızca resmi HTTPS mağaza hostları kabul edilir.
- Temsili telefon ekranı gerçek native screenshot veya App Store ekran görüntüsü olarak sunulmaz.
- GitHub Pages workflow mevcut; gerçek GitHub hesabında çalıştırılmadı. Gerçek URL, HTTPS ve App Store bağlantı denetimi yayın sonrası yapılmalı.
